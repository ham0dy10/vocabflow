# VocabFlow UI System

The frontend uses a focused learning workspace instead of a dashboard-heavy layout.

- Desktop navigation is a compact top bar.
- Language, theme, and account controls live in the top bar.
- The home page answers one question first: what should I do now?
- Arabic changes text alignment where needed, but the application shell remains LTR.
- Surfaces are flat with 1px borders; shadows are reserved for popovers and toasts.
- One accent token is used sparingly for progress and semantic emphasis.
- Review, practice, quiz, library, and progress screens share the same component tokens.
- Mobile uses a top navigation drawer instead of a sidebar.
